title: The report stays in CI/CD
status: accepted

## Context

The pre-scan JSON report that triggers agent review could either be
generated by this daemon or produced upstream by the existing CI/CD
pipeline, which already has full build context (checked-out repo,
migration tooling, linters).

## Decision

Report generation stays in CI/CD, not folded into this app. The contract
between CI/CD and the daemon is a `schema_version` field on the report,
validated against a JSON schema on ingest, rather than merging the two
systems. An unrecognized/unsupported `schema_version` is a hard-fail.

## Consequences

The report generator can evolve independently of the daemon's release
cycle. The daemon doesn't need to duplicate analysis logic (linters,
migration risk detection) that CI/CD already owns. See
[[hard-fail-philosophy]] for the failure-handling rule this depends on.
